# ShareGPT 1.0.10：更可靠的聊天、独立资料与连接恢复

1.0.10 重点打磨已经在用的功能：读过的聊天不再反复跳回旧位置，翻译和掉线恢复更可控，个人与团队资料也能清楚地分开保存。

本版正在准备发布，正式下载以 [GitHub Releases](https://github.com/Sjeary/ShareGPT/releases/latest) 为准。

## 聊天阅读更连贯

- 未读消息只保留一条分隔线，定位最早未读的位置，读到最新后自动消失。上下线提示不再反复插入未读横线。
- 已经读到最底部，再次进入会话仍停在最新消息；主动翻看历史时，返回会保留原阅读位置。
- 改善公共房间在重新连接和历史加载后的消息顺序。
- 双表情组合遇到网络波动时保留原表情，并提供重试入口；恢复网络后无需重启。快速切换不同组合时，也不会混用上一组图片状态。

## 翻译、重连和环境重建更稳

- 停止阅读翻译或发送预览时，不会因请求恰好完成而误发第二次翻译；关闭翻译栏会结束当前任务。
- 掉线后可以点击窗口右上角“重新登录”，不必先退出账号。需要更新密码时可直接输入，网络失败后保留填写内容。
- 修复 Windows 删除高级环境后无法再次创建的问题；失败的旧环境清理可以重试，不会影响新建环境。

## 资料按账号和工作区保存

- 个人工作区与不同团队账号分别保存日历、待办、笔记和专注记录，团队聊天历史也按账号区分。
- 切换工作区前保存正在编辑的内容；保存或读取遇到问题时提供重试，并保留原资料。
- 旧资料可以从“账户 → 本机资料”按类别接续，确认后复制到当前工作区，原件继续保留。
- 改善多设备同步时示例日程反复出现、已删除内容再次回来的情况。删除记录保护需要配套升级协作服务器。
- 新用户的日历、待办、笔记和专注入口默认关闭，可到“账户”设置按需开启；已有用户的选择保留。

## 团队网络与管理

- 普通成员可以查看管理员下发的只读连接参数，并切换已经获准使用的代理方式；连接字段仍由管理员维护。
- 管理员可集中管理三种 AI 的默认出口、线路目录和成员授权，查看 ChatGPT、Claude、Gemini 的成功发送次数与成员排行。
- 管理员确认服务器入口变化仍指向同一套服务后，可接续本机原账号与 AI 网页环境。不同团队、不同账号及个人工作区仍相互独立。
- 加强账号管理、聊天权限及服务端资料保存保护；配置导出默认不包含密钥。

## 升级前留意

| 设备 | 发布后选择的安装包 |
| --- | --- |
| Apple 芯片 Mac | `sharegpt-1.0.10-arm64.dmg` |
| Windows x64 | `sharegpt-1.0.10.exe` |

升级无需先卸载：Windows 使用新版安装程序，Mac 退出旧应用后将新版拖到“应用程序”替换。其他附件用于备用下载和自动更新。

本版沿用 1.0.9 的分发方式：Windows 安装包未签名，Mac 使用 ad-hoc 签名且未经 Apple 公证，首次打开可能出现系统安全提示。请只从本仓库 Release 下载；Mac 的首次打开方式可参考 [Apple 官方说明](https://support.apple.com/102445)。企业管理的设备请遵循所在组织的安装要求。

首次接续旧资料时，先进入资料应归属的个人工作区或团队账号，再打开“账户 → 本机资料”选择类别并确认。已有资料不会被覆盖，旧原件继续保留。AI 网站账号仍需使用自己的账号登录，本版不提供免密共享第三方账号。

新协作服务继续兼容已有 1.0.x 客户端；新客户端连接旧服务器时，只能使用旧服务器支持的功能。服务器侧的权限、删除记录和数据恢复修复，需要管理员单独升级后生效，桌面安装不会自动升级服务器。

管理员升级前请备份数据与加密密钥，参见[自托管指南](https://github.com/Sjeary/ShareGPT/blob/v1.0.10/docs/SELF_HOSTING.md)。完整变更见[更新日志](https://github.com/Sjeary/ShareGPT/blob/v1.0.10/CHANGELOG.md)。
