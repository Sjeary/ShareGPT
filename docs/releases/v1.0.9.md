# ShareGPT 1.0.9：个人与团队双工作区、全新翻译工作台

这次更新让 ShareGPT 既能作为个人 AI 桌面工作区，也能继续服务小团队。翻译、聊天和账号切换流程经过重新整理，减少误覆盖、重复等待和界面遮挡。

## 下载与安装

| 设备 | 下载文件 |
| --- | --- |
| Apple 芯片 Mac | `sharegpt-1.0.9-arm64.dmg` |
| Windows x64 | `sharegpt-1.0.9.exe` |

Mac 打开 DMG 后，将 ShareGPT 拖到“应用程序”；升级前先退出正在运行的 ShareGPT，再替换旧应用。Windows 运行 EXE 安装程序，或使用客户端的更新入口。**不需要先卸载，更不要清除应用数据。** 本次不提供 Intel Mac 原生安装包。

**首次安装提示：本版沿用历史分发方式，Windows 安装包未正式签名，Mac 应用只有 ad-hoc 签名、未经 Apple 公证。** 因此可能出现“未知发布者”“无法验证开发者”或 SmartScreen 提示，不承诺在所有受管理设备上可运行。

- 只从 `github.com/Sjeary/ShareGPT` 的本 Release 下载，确认文件名及来源后再决定是否安装。
- Mac 若仅提示无法验证开发者，可按 [Apple 官方说明](https://support.apple.com/102445)在“系统设置 → 隐私与安全性”查看是否提供单独允许打开的选项。
- Windows 若仅提示未知发布者或应用尚未建立信誉，可查看提示详情后自行决定是否继续；组织策略或 Smart App Control 阻止运行时，请联系设备管理员。
- 如果提示恶意软件、文件损坏或被组织策略禁止，请停止安装并反馈。不要关闭 Gatekeeper、Defender 等系统安全功能，不需要运行移除隔离属性的终端命令。

`sharegpt-sender-1.0.9-arm64.dmg` 是同一个 Mac 安装包的旧客户端下载别名，不是另一款应用。ZIP 是 Mac 备用分发包；`latest.yml` 和 `.blockmap` 供 Windows 自动更新使用，无需手动打开。

## 个人使用与团队协作，各自独立

- 首次启动可选择“连接团队”或“仅在本机使用”，不再混淆两种入口。
- 个人工作区不用团队账号，可配置自己的代理和翻译接口；团队聊天、在线成员和管理功能只在团队工作区显示。
- 从“账户”随时切换。个人与团队的代理、翻译设置和 ChatGPT、Claude、Gemini 网页资料分别保存，不会把一边的登录状态和历史会话带到另一边。
- 个人工作区也可按 AI 服务清除本地网页数据，不再被团队登录要求挡住。

## 翻译先预览，再决定怎么用

- **阅读翻译**用于阅读和复制，不会自动把译文塞进 AI 输入框。
- **写给 AI**先生成可编辑预览，可选仅译文或原文加译文，确认后才插入网页。
- 网页已有草稿时，可选择追加、替换或取消，避免覆盖正在编辑的内容。
- 支持选中文字、读取页面、翻译风格、术语表，以及默认关闭的发送语言提醒。
- 翻译中可停止；关闭侧栏、切换页面或修改设置后，旧任务不会继续写入当前页面。
- 侧栏支持拖动调宽、双击恢复默认，窄窗口自动调整布局，宽度按工作区保存。

## 管理员配置，成员直接选择

- 管理员可提供多套团队翻译服务，设置默认项，决定全部成员或指定账号可以使用哪些服务。
- 团队 API Key 在服务器端加密保存，不下发给成员；管理端可查看请求量、token 和估算费用，不记录原文和译文。估算费用以服务商实际账单为准。
- 团队主页的代理参数只由管理员修改，普通成员和高级用户不会误改管理员配置；个人工作区仍可编辑自己的连接。
- 可为 ChatGPT、Claude、Gemini 分别推荐默认线路。高级用户仍只能选择自己获授权的线路。
- 团队网络配置变更后会提示并停止旧线路；同步完成后，请重新开启代理。

## 聊天与界面更顺手

- 消息菜单、表情回应和长消息面板会避让窗口边缘，靠近底部也能完整操作。
- 切换会话可保留本次运行期间的文字草稿；发送失败不清空输入。退出应用后的草稿恢复暂不支持。
- 阅读旧消息时不再被新消息强行拉到底部；查看引用后可以返回原阅读位置。
- 侧栏持续显示在线人数与成员总数；右上角消息提示可跳转并定位到相关消息。
- 个人资料编辑适配窄窗口，保存失败保留已填内容。
- 修复 Mac 全屏标题栏位置、输入框多余阴影；AI 标签横向滚动提示仅在指针移入后显示。

## 更稳的网页与数据保存

- 减少首次打开 AI 网页时重复的线路检查与初始化；切回同一健康页面不再反复等待。实际速度仍受网络和 AI 网站影响。
- 改善快速切换、系统唤醒和网页进程异常后的恢复，继续使用对应分区内的网页登录资料。
- 不同服务器和账号的数据保持隔离；退出账号或权限变化不会删除已保存的 AI 网页环境。
- 协作服务器的聊天历史和发送统计增加备份恢复保护，损坏且无法恢复时保留原件并报错，不再悄悄清空。恢复可能缺少最近记录，需要管理员核对。
- 网络诊断区分“出口实测”和“配置检查”，不再把尚未验证的项目说成“防泄漏通过”。

## 团队升级须知

现有 `1.0.x` 客户端仍可连接新服务器；新客户端连接旧服务器时，继续使用旧服务器支持的功能。共享翻译、管理员用量报表及服务端历史备份保护需要升级协作服务器，单独安装新版桌面端不会自动升级服务器。

管理员请先备份服务器数据和翻译加密密钥，再按 [自托管指南](https://github.com/Sjeary/ShareGPT/blob/v1.0.9/docs/SELF_HOSTING.md)升级。暂时的服务器故障不会被当作清空配置的指令。

ShareGPT 不附带公共团队服务器、代理节点、第三方 AI 账号或 API Key；AI 网站是否继续保持登录仍由其会话有效期和安全策略决定。

完整变更见 [更新日志](https://github.com/Sjeary/ShareGPT/blob/v1.0.9/CHANGELOG.md)。
