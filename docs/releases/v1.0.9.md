# ShareGPT 1.0.9：个人与团队双工作区、全新翻译工作台

一个人用自己的代理和 AI 服务，也可以连接团队一起协作。1.0.9 带来了独立的个人工作区、重新设计的翻译流程，以及更顺手的聊天和网页切换体验。

## 下载与安装

| 设备 | 下载文件 |
| --- | --- |
| Apple 芯片 Mac | `sharegpt-1.0.9-arm64.dmg` |
| Windows x64 | `sharegpt-1.0.9.exe` |

Mac 打开 DMG 后，将 ShareGPT 拖到“应用程序”；升级前先退出旧应用，再替换。Windows 运行安装程序，或使用应用内更新。**升级沿用原有数据，无需先卸载。**

本次提供 Apple 芯片 Mac 和 Windows x64 安装包，暂不提供 Intel Mac 原生安装包。

首次安装可能出现系统安全提示：本版 Windows 安装包未签名，Mac 版未经 Apple 公证。请确认下载自本仓库；Mac 的首次打开方式可参考 [Apple 官方说明](https://support.apple.com/102445)。企业管理的设备请遵循所在组织的安装要求。

其他附件供备用下载和自动更新使用，普通用户选择上表安装包即可。

## 个人使用与团队协作，各自独立

- 首次启动可选择“连接团队”或“仅在本机使用”。
- 个人工作区不用团队账号，可配置自己的代理和翻译接口；团队聊天、在线成员和管理功能只在团队工作区显示。
- 从“账户”随时切换。个人与团队分别保留自己的代理、翻译设置和 ChatGPT、Claude、Gemini 登录状态及历史会话。
- 个人工作区也可按 AI 服务管理和清除本地网页数据。

## 翻译先预览，再决定怎么用

- **阅读翻译**：翻译手动输入、网页选中文字或当前页面，方便阅读和复制。
- **写给 AI**先生成可编辑预览，可选仅译文或原文加译文，确认后才插入网页。
- 网页已有草稿时，可选择追加、替换或取消。
- 支持选中文字、读取页面、翻译风格、术语表，以及默认关闭的发送语言提醒。
- 翻译过程中可随时停止。
- 侧栏支持拖动调宽、双击恢复默认，窄窗口自动调整布局，宽度按工作区保存。

## 管理员配置，成员直接选择

- 管理员可提供多套团队翻译服务，设置默认项，决定全部成员或指定账号可以使用哪些服务。
- 团队 API Key 加密保存在服务器；管理端可按用户和配置查看请求量、token 与估算费用。
- 团队主页的代理参数由管理员维护，成员直接使用下发配置；个人工作区仍可编辑自己的连接。
- 可为 ChatGPT、Claude、Gemini 分别推荐默认线路。获授权的高级用户还可为多个 AI 环境选择线路。
- 团队网络配置变更后会提示并停止旧线路；同步完成后，请重新开启代理。

## 聊天与界面更顺手

- 消息菜单、表情回应和长消息面板会避让窗口边缘，靠近底部也能完整操作。
- 切换会话可保留本次运行期间的文字草稿，发送失败后可继续编辑。草稿目前仅在应用运行期间保留。
- 阅读旧消息时保持当前位置，可通过新消息提示回到底部；查看引用后可以返回原阅读位置。
- 侧栏持续显示在线人数与成员总数；右上角消息提示可跳转并定位到相关消息。
- 个人资料编辑适配窄窗口，保存失败保留已填内容。
- 修复 Mac 全屏标题栏位置、输入框多余阴影；AI 标签横向滚动提示仅在指针移入后显示。

## 更稳的网页与数据保存

- 减少打开 AI 网页时的重复检查，切回已打开的页面更直接。
- 改善快速切换标签、系统唤醒和网页异常后的恢复。
- 加强不同账号的设置与网页登录资料隔离，Notes AI 切换文档时的任务处理更稳定。
- 协作服务器新增聊天历史和发送统计的备份恢复保护。
- 网络诊断分别展示出口检测结果和配置状态，便于查看连接情况。

## 团队升级须知

现有 `1.0.x` 客户端仍可连接新服务器；新客户端连接旧服务器时，继续使用旧服务器支持的功能。共享翻译、管理员用量报表及服务端历史备份保护需要升级协作服务器，单独安装新版桌面端不会自动升级服务器。

管理员请先备份服务器数据和翻译加密密钥，再按 [自托管指南](https://github.com/Sjeary/ShareGPT/blob/v1.0.9/docs/SELF_HOSTING.md)升级。

完整变更见 [更新日志](https://github.com/Sjeary/ShareGPT/blob/v1.0.9/CHANGELOG.md)。
