# 三网页端双语翻译

ChatGPT、Gemini 和 Claude 共用同一套双语交互，所有已登录用户都可以使用。网页保持站点原始语言，翻译内容只在 ShareGPT 外壳中展示。高级权限只控制多条托管线路和相互隔离的多 AI 环境，不是使用翻译的前提。

## 使用流程

- 阅读选区：在网页中选中文字，右键选择“翻译选中文字”，侧栏自动翻译。
- 连续划词：可按账号开启“选中文字后自动翻译”（默认关闭）；只在三家 AI 官方网页中响应受信任的网页选区操作，输入框与编辑器中的选区不会触发。Claude 手动打开的任意外部网页只支持显式右键翻译选区。
- 阅读全文：打开翻译侧栏，点击“整页翻译”。网页正文不会被替换。
- 中文提问：在“中文提问”中输入，选择“预览译文”“翻译并填入”或“翻译并发送”。默认网页接收语言为英文。
- 发送保护：直接在网页输入框中输入明显非目标语言并按 Enter 或点击发送时，ShareGPT 会暂停发送并要求确认。

## 低侵入边界

- 中文提问不会先写入网页输入框；站点只收到最终填入的目标语言文本。
- 阅读译文不修改网页 DOM，也不把译文覆盖到站点内容中。
- 文本作为序列化数据传入固定的 Chromium 隔离世界脚本；`input` / `textarea` 使用原生 value setter，`contenteditable` 优先使用 `execCommand('insertText')` 并在必要时回退到文本节点替换，不会把用户文本拼接成可执行代码。
- 鼠标发送保护运行在 Chromium 隔离世界中，站点主世界不能读取守卫状态。
- 发送保护按正常官方 AI 页面不是恶意执行方的模型设计；若官方页面本身被攻陷，内嵌浏览器无法阻止站点在更早的可信输入处理阶段执行自身逻辑。
- 任何内嵌浏览器都不能保证对站点“绝对不可检测”；这里提供的是低侵入设计，不是绕过站点安全或风控的承诺。

## 语言判断

发送保护使用本地 Unicode 文字系统判断。英文目标下能可靠提醒中文、日文、韩文、西里尔文、阿拉伯文等内容。仅使用拉丁字母的不同语言无法在不调用远程检测服务的情况下可靠区分，因此不会为此阻断发送。
