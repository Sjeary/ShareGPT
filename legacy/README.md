# 历史实现

当前桌面客户端使用 `src/main/` 和 `src/renderer-next/`。本目录集中保留已被替代的实现，供兼容测试和历史对照使用，不进入当前客户端安装包。

| 位置                  | 用途                                                                              |
| --------------------- | --------------------------------------------------------------------------------- |
| `renderer/`           | 旧 HTML/JavaScript 客户界面与个人资料窗口；其中的账号切换协调器仍由兼容测试覆盖。 |
| `receiver/build.json` | 旧接收端桌面的构建配置；从仓库根目录解释资源和源码路径。                          |

当前客户功能应在 `src/renderer-next/` 中维护。`src/main/main_receiver.js` 仍供旧模式兼容验收调用，共用现有主进程实现；这不构成第二个日常客户入口。

团队集中代理、自托管协作服务和管理员控制台继续由各自现行实现及 `docs/SELF_HOSTING.md` 支持，不属于本目录的历史桌面界面。
